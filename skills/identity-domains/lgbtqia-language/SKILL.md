## Purpose

Write about sexual orientation and gender identity accurately and respectfully,
using current community-preferred terminology and neutral defaults where unknown.

## When to use

Any content involving LGBTQIA+ people, gender identity/expression, transition,
or orientation.

## Rules

**R1 — Initialisms.** Default to LGBTQIA+ (or 2SLGBTQIA+ when Two Spirit
inclusion matters). Respect authors' valid alternatives (LGBTQ+, LGBT, GLBT,
QIPOC…). Don't use the umbrella when you mean a subgroup — say "transgender
people", not "the LGBTQ+ community", for trans-specific issues.

**R2 — Identity terms table (avoid → use):**

| Avoid | Use |
|---|---|
| biologically male/female; born male/female | assigned/designated/assumed male/female at birth (use with care; identity ≠ simplified biology) |
| deviant, disordered, perverted | — never; if analysing historical attitudes, mark the bias explicitly |
| Gender Identity Disorder (GID) | gender dysphoria (note: not all trans people have/want a diagnosis) |
| hermaphrodite | intersex (intersex status ≠ orientation/identity) |
| homosexual (for people) | gay, gay person, lesbian, bisexual, queer etc. as appropriate (clinical/anti-LGBTQ history) |
| practising / avowed / admitted / confessed [gay person] | out / openly [gay] (some also avoid "openly") |
| pre-op / post-op | transition / transitioning (surgery neither required nor defining) |
| preferred pronouns; male/female pronouns | pronouns (not necessarily tied to identity or biology) |
| sex change / sex change operation / SRS | gender confirmation surgery (SRS still used by some clinicians; can be seen as reductive) |
| sexual preference | sexual orientation, orientation |
| sodomy, sodomite | — only inside quoted legal/historical text with bias marked |
| a transgender (n.), transgenders, transgendered, transgenderism | transgender person (adjective only; "-ism" is anti-trans framing) |
| transsexual (blanket use) | only self-referentially or per stated identity; never as noun |
| transvestite | cross-dresser (per person's preference); neither implies being trans or gay; ≠ drag queen/king |
| tranny | — slur; never generate (G12) |
| bathroom bill | name the actual law/ordinance (politically charged simplification) |
| gay agenda / homosexual agenda; special rights | refer to the specific issue; equal rights, equal protection |
| freshman | first-year student |

**R3 — Pronoun discipline.** Apply `gender.pronoun-strategy` R1 absolutely:
stated pronouns win; scare quotes around pronouns/names are invalidating and
prohibited; singular they is the neutral default when pronouns are unknown and
unaskable.

**R4 — No generalisation.** Avoid "gay lifestyle" and similar homogenising
phrases; LGBTQ+ experience is diverse.

**R5 — Reclaimed slurs.** Terms reclaimed by communities (queer, dyke) may appear
only self-referentially or with clear community framing; casual outsider use is
prohibited (G12).

**R6 — Gendered metaphors.** Replace Mother Nature / Father Time with neutral
alternatives (nature, time) unless quoting.

**R7 — Occupational terms.** chairman→chair; policeman→police officer;
fireman→firefighter; steward(ess)/air hostess→flight attendant;
actor/actress→actor; congressman→congressional representative;
mailman/postman→mail carrier (see substitution tables §1).

**R8 — Self-check battery (INTELLECT):**
1. Any 'man/men'-compounds referring to people who may not be men?
2. Was mentioning sex/gender necessary?
3. Any occupational stereotypes?
4. Same kinds of information given about different genders?
5. Generic he/him/his for people who may not use he/him?

## Guardrails

- G2/G11: never out anyone; never frame being LGBTQ+ as shameful, negative, or a
  "preference".
- G5: historical/legal analysis may quote derogatory terms with explicit
  bias-marking, minimised.

## Uncertainty

Individual terminology (transsexual, queer, cross-dresser) is personal. For a
specific person, mirror their own words; for general writing, use the table's
right column.
