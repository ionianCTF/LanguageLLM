## Purpose

Use disability language that is neutral, accurate, respects active personhood, and
follows the social model while honouring individual preference.

## When to use

Any content mentioning disability, health conditions, accessibility, or
body/mental-function characteristics.

## Rules

**R1 — Model framing.** Default frame = social model: people *have impairments*
and are *disabled by societal barriers*. "Disabled people" under this model means
people with long-term impairments facing discriminatory barriers. Not everyone
uses this model — respect identity-first users ("disabled person") and
person-first users ("person with a disability") alike (G7).

**R2 — Active personhood.** Reject passive/victim framings: no "suffers from",
"afflicted by", "victim of", "confined to", "wheelchair-bound". State the
condition factually; wheelchairs enable mobility ("wheelchair user").

**R3 — No "normal" as contrast.** The counterpart to disabled people is
"non-disabled people", never "normal".

**R4 — Terminology table (avoid → use):**

| Avoid | Use |
|---|---|
| able-bodied | non-disabled |
| afflicted by / suffers from / victim of | has [condition] |
| the blind | blind people, visually impaired people, blind and partially sighted people |
| (is) colour blind | (has) colour vision deficiency |
| cripple, invalid, spastic | disabled person; person with cerebral palsy |
| deaf and dumb, deaf mute | deaf, user of British Sign Language, person with a hearing impairment |
| dwarf, midget | someone with restricted growth / short stature; person with dwarfism |
| an epileptic / diabetic / depressive | person with epilepsy / diabetes / depression |
| fits, spells, attacks | seizures |
| the handicapped, the disabled | disabled people |
| hearing impaired | D/deaf or hard of hearing |
| mentally handicapped, retarded, subnormal | person with a learning disability (pl.: with learning disabilities) |
| mental patient | person with a mental health condition |
| senile | person with dementia |
| normal (people) | non-disabled people/person |
| wheelchair-bound, confined to a wheelchair | wheelchair user |

**R5 — D/deaf capitalisation nuance.** Capital-D **Deaf** = cultural membership of
the Deaf community (use for cultural topics). Lower-case **deaf** = audiological
hearing loss. Preserve the writer's intended sense; ask if unclear.

**R6 — Specificity.** Name the actual condition when relevant ("person with
Down's Syndrome", not "a Down's"); otherwise stay general.

**R7 — Intersectionality.** Represent disabled people in roles beyond patient/
dependent (EIGE-2024): professionals, parents, athletes — see multimodal-inclusion
for visuals.

## Guardrails

- G2/G7: individual preference beats table defaults; both person-first and
  identity-first are acceptable coherent choices.
- G10: avoid deficit framing ("despite her disability she…" → describe
  achievement directly).

## Uncertainty

Condition-specific etiquette evolves; if unsure about a specific community's
current preference, use the general respectful form and flag low confidence.
