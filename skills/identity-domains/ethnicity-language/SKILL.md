## Purpose

Refer to ethnic and racial groups with precision, respect, and current
conventions; avoid homogenisation, othering, and euphemistic or loaded historical
terms.

## When to use

Any content mentioning ethnicity, race, national origin, migration status, or
Indigenous peoples.

## Rules

**R1 — Relevance + specificity.** Don't mention ethnicity unless relevant (G3).
When relevant, be as specific as possible ("Nigerian British", "people from the
Chinese ethnic group" when ethnicity—not nationality—is meant). A person is never
just "ethnic"; everyone has an ethnicity.

**R2 — No default whiteness.** If ethnicity of people of colour is mentioned in a
context, mention White people's ethnicity in the same context. Alphabetise
ethnicity lists; don't default "White" first.

**R3 — Capitalisation.** Capitalise Black, Brown, Indigenous, White in racial/
ethnic/cultural contexts. Lower-case "white" as deliberate protest is acceptable;
do not switch styles mid-document.

**R4 — Terminology table (avoid → use):**

| Avoid | Use |
|---|---|
| Afro-American; Afro-Caribbean | African American; African Caribbean (no hyphen); Black |
| BAME / BME | people of colour; minority ethnic; BIPOC; better: name the specific group |
| Blacks (noun) | Black people |
| coloured | Black; multiracial; people of colour; minority ethnic; BIPOC |
| exotic (for people) | — othering; name specific ethnicity if relevant |
| Gypsy (as umbrella for Roma) | Roma, Sinti, Travellers, Ashkali, Manush, Jenische, Kaldaresh, Kalé (as appropriate); "Gypsy" fine for UK/IE Gypsy groups specifically |
| host society | society receiving migrants |
| Indigenous [Nationality] e.g. "Indigenous Canadians" | Indigenous people in [Country]; "[Country's] Indigenous people" also paternalistic—prefer "in" |
| Jew (derogatory/verb use) | factual use only: person of Jewish ethnicity / practises Judaism |
| Kurd(s)/Kurdish (for all in region) | Kurdistani(s) where regional inclusivity intended (note generational uptake varies) |
| minorities (for individuals) | name their ethnicity; "minority ethnic" prioritises group membership correctly |
| mixed; mixed race people | biracial/multiracial (check preference); people with a mixed ethnic background; dual heritage |
| Native / Aboriginal (Canada/Americas) | Indigenous |
| non-White | people of colour; minority ethnic; BIPOC |
| oriental (people) | Asian; Chinese; Japanese (as appropriate) |
| race (as analytic category) | ethnicity (self-defined social grouping; "race" categories lack objective basis) |
| racially diverse (= not-White) | people of colour; minority ethnic; BIPOC |
| redskin | — slur; Indigenous People/s; Indigenous people in America |
| slave (noun for person) | enslaved person/people; use names where known |
| slave master/owner | enslaver; those who held people in slavery |
| slave breeding | forced reproduction |
| Third World | developing countries (quote-mark legacy uses only) |
| tribe (US Indigenous context) | nation; people (verify recognised nation name) |
| West Indian | African Caribbean (with care re: homogenisation) |
| White Gypsy/Roma (slash) | White Gypsy and Roma ethnic group |

**R5 — Slavery language.** Enslavement is a condition imposed on people, not an
identity: "enslaved" disaggregates condition from being. Never call sexual abuse
of enslaved people "sex"; centre abusers' crimes (abuser, rapist, enslaver who
sexually abused).

**R6 — Physical characteristics.** Use correct terms for hair etc.
(cornrows, braids); verify with the subject when possible.

## Guardrails

- G5/G12: slurs appear only inside quotes with critical framing, minimised.
- G6: umbrella terms are fallbacks; specificity wins whenever known.
- Context note: EU institutions use "Roma" as umbrella even though not all
  Romani-speaking groups self-identify so — state the convention being followed.

## Uncertainty

Group-specific preferences vary by country and generation (Kurdistani, Gypsy,
multiracial). Default to the most specific respectful term known; flag low
confidence rather than guessing identities.
