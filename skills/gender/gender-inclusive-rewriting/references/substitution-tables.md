# Substitution Tables — Gendered → Inclusive

Reference data for `gender.gender-inclusive-rewriting` R4. Compiled from EIGE-2019
ch.6, UNW-EN, CAPE-2023, IBEC-2015. All entries are `avoid → prefer` pairs.
Apply only when meaning is preserved (GUARDRAILS G1). Latin-root false positives
(manual, manufacture, manipulate, manuscript) are NOT gendered — never substitute.

## 2. Generic-humanity terms ("false generics")

| Avoid | Use |
|---|---|
| man (for humanity) | person, individual, human being, people |
| mankind | humankind, humanity, human beings, people |
| man's achievements | human achievements |
| the nature of man | the nature of the human being |
| man in the street / the average man | average person, ordinary people, people in general |
| every man for himself | everyone for themselves |
| to a man | to a person, without exception |
| best man for the job | best candidate/person for the job |
| Joe public | an average citizen |
| gentlemen's agreement | informal arrangement |
| man-made | synthetic, artificial, machine-made, human-induced (disaster) |
| manpower | workforce, staff, personnel, human resources, labour force |
| man-hours / man-hour | person-hours, staff hours, staff hour |
| workmanship | handiwork, expertise, craftsmanship→quality of construction |
| brotherhood | kinship, community |
| fatherland | native land, homeland |
| mother tongue | native language, first language |
| no man's land | unclaimed territory, uninhabited zone |
| where no man has gone before | where no one has gone before |
| a man's home is his castle | one's home is one's castle |

| master of ceremonies | host, emcee |

| Frenchman | French person, French people |
| tribe (for Indigenous peoples, US context) | nation, people (research the specific nation) |

## 3. Address and groups

| Avoid | Use |
|---|---|
| ladies and gentlemen | everyone, colleagues, delegates, guests, members |
| hey guys (mixed group) | hey everyone, hi all, folks, team |
| the guys (mixed group) | the group, everyone, the team |

| the girls in the office | the women in the office, colleagues |

## 4. Family and relationship terms (CAPE)

| Avoid (when gender unknown/irrelevant) | Use |
|---|---|
| father / mother | parent |
| father-in-law / mother-in-law | parent-in-law |
| stepfather / stepmother | stepparent |
| brother / sister | sibling |
| stepbrother / stepsister | stepsibling |
| son / daughter | child |
| grandson / granddaughter | grandchild |
| husband / wife | spouse, partner, significant other |
| aunt / uncle | parent's sibling (less common: pibling) |
| niece / nephew | sibling's kid (less common: nibling) |

Note: use specific terms when gender/family role IS relevant and known.

## 5. Adjectives with gendered connotations (apply to any gender)

| Avoid (esp. describing women) | Use |
|---|---|
| bossy, pushy | assertive |
| emotional, hormonal | passionate, enthusiastic, empathetic |
| ditzy | silly (say what you mean about the behaviour) |
| frigid | lacking sexual responsiveness (only if clinically relevant) |
| frumpy, mumsy | dowdy, old-fashioned (prefer precise description) |
| shrill | high-pitched, grating |
| hysterical | irrational, furious, out of control (be precise) |
| loose (sexual sense) | — no neutral equivalent needed; question why the judgement is being made |
| virile | strong, energetic, vigorous |
| ladylike (as weak) | weak, soft (describe the actual quality) |
| manly, virile (as praise-default) | strong, courageous, robust |

Test (EIGE): "Would I use this adjective to describe a different gender in the same
context?" If not, find a term without gender connotation.

## 6. Semantic non-equivalence pairs (diverged connotations)

governor/governess · master/mistress · patron/matron · sir/madam ·
bachelor/spinster · host/hostess — check connotations before using the feminine
form; prefer rephrasing ("unmarried woman" only if marital status is relevant).

## 7. Fixed-order phrases to alternate

men and women · boys and girls · king and queen · lord and lady ·
husband and wife · boyfriend and girlfriend · brother and sister ·
mother and father · sir/madam — vary the order across a document; do not always
place the male term first.

## 8. Terms of address / endearment (workplace & formal contexts)

| Avoid | Use |
|---|---|
| my dear, darling, love, dear (to strangers/non-intimates) | name, role ("excuse me, sir/ma'am" only if known), nothing |
| baby, honey (professional context) | name |
| Miss / Mrs. | Ms. (unless individual prefers otherwise) |
| Mr and Mrs John Smith | Jane and John Smith; Ms Jane and Mr John Smith |
| maiden name / married name | last name / previous name |
